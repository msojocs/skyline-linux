# Runtime translation units and internal headers.
#
# [common] is compiled into the standalone libskyline.so (Dart API DL only) and
# the engine's embedded runtime.  [embedded] is compiled only into the engine
# embedder target, which defines SKYLINE_EMBEDDED=1.  The embedded replay is
# split into `appservice_*` modules; `skyline_runtime_stub.cc` keeps the
# bootstrap/ABI surface and the exported no-op stubs shared by both builds.

# tools/conformance-gaps.js and native/CMakeLists.txt; all three consume it.
